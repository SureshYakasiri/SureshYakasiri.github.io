# Yakasiri Suresh — Game Designer Portfolio

A modern, high-performance portfolio website built with a **Gaming Hardware × Game Designer** aesthetic. 

Designed for **Yakasiri Suresh**, Game Designer and B.Sc Game Art & Design student at **ICAT Design & Media College**.

---

## 🎮 Visual Design & Art Direction

- **Hardware Aesthetic**: Inspired by high-end gaming battlestations, custom water-cooled rigs, illuminated mechanical keyboards, low-latency gaming peripherals, and circuit trace matrices.
- **Color Palette**:
  - Background: Deep Obsidian Charcoal (`#07090d`, `#0d1219`)
  - Accent: Vibrant Neon Green (`#00ff66`) with custom interactive RGB lighting switcher (Neon Green / Cyber Cyan / Stealth White)
  - Typography: Crisp White & Slate Grey
- **Game Design Blueprints**: Custom SVG vector schematics representing level greyboxing, spatial mechanics, and systems balancing for all featured projects without relying on fabricated gameplay screenshots.

## 🌐 Deploying to GitHub Pages (2 Minutes)

This website uses pure HTML5, CSS3, and Vanilla JavaScript—requiring **zero build steps** or node dependencies.

### Option A: Hosting at `https://fein999x.github.io`
1. Create a new repository on GitHub named `fein999x.github.io` (or any repository name like `portfolio`).
2. Push or upload these files (`index.html`, `css/`, `js/`, `assets/`, `README.md`) to the root of your repository:
   ```bash
   git init
   git add .
   git commit -m "Initial release of Game Designer portfolio"
   git branch -M main
   git remote add origin https://github.com/fein999x/fein999x.github.io.git
   git push -u origin main
   ```
3. Go to **Settings** > **Pages** in your GitHub repository.
4. Under **Branch**, select `main` (and `/root`), then click **Save**.
5. Your portfolio will be live in 60 seconds!
